## ➕ How to Add New Resources & Folders

When you have a new set of materials or documents to share:

1. **Create your folder** in the repository root (e.g., `2-DSA-Notes` or `3-System-Design`).
2. **Put your files/PDFs/notes** into that folder.
3. **Add a row to the Directory Index** above:
   ```markdown
   | **02** | [📁 `2-Your-Folder-Name`](./2-Your-Folder-Name/) | **Topic Name** | X Files | [Open Folder](./2-Your-Folder-Name/) |
   ```
4. **Create a section** in this README with direct links to your files.
